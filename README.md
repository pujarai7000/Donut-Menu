#  Donut Menu Website

##  Project Overview

Donut Menu is a front-end web development project focused on creating a visually appealing and easy-to-navigate menu for a donut shop.

The project is part of my hands-on learning journey in web development, where I practice building web pages and improving their design and usability.

## 🛠️ Technologies Used

- **HTML5** – Webpage structure and content
- **CSS3** – Styling, layout, and visual design

##  Project Highlights

- Donut-themed menu interface
- Organized presentation of menu items
- Focus on clean design and readability
- Practice with front-end web development concepts

##  Learning Objectives

Through this project, I aim to:

- Strengthen my understanding of HTML and CSS
- Improve webpage layout and styling skills
- Learn how to organize a front-end project
- Gain experience building user-friendly interfaces

## Future Improvements
